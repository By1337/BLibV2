# Копирование ресурсов

`ResourceUtil.resourceStream(plugin, entries...)` возвращает неизменяемый билдер.
Можно передать явные пути файлов или `menu/*`: такой шаблон выбирает все файлы
под `menu/`, включая вложенные каталоги. Другие glob-шаблоны не поддерживаются.
Поиск файлов и чтение ресурсов происходят только при вызове метода сохранения.

Сохранить собственные меню без повторения `menu/menu`:

```java
ResourceUtil.resourceStream(this, "menu/*")
        .to(new File(getDataFolder(), "menu"))
        .stripPrefix("menu/")
        .storeIfFolderNotExist();
```

Сохранить меню аукциона в папку другого плагина:

```java
ResourceUtil.resourceStream(this, "menu/*")
        .to(new File(bmenuPlugin.getDataFolder(), "menu/bauc"))
        .stripPrefix("menu/")
        .storeIfFolderNotExist();
```

В обоих примерах `menu/home.yml` станет `home.yml` внутри заданной папки,
а `menu/rent/confirm.yml` — `rent/confirm.yml`.

- `to(File)` задаёт корневую папку назначения; по умолчанию это data folder источника.
- `stripPrefix(String)` убирает исходный префикс из имён сохраняемых файлов.
- `pathMutator(Function<String, String>)` задаёт произвольное преобразование пути
  назначения вместо `stripPrefix`. На вход подаётся исходный путь с `/` в качестве
  разделителей и без начального `/`. Последний вызов настройки преобразования
  заменяет предыдущий.
- `storeIfFolderNotExist()` проверяет существование папки один раз перед копированием.
  Если она уже есть, не читает ресурсы и ничего не дополняет, даже если папка пустая.
- `storeIfNotExist()` копирует каждый отсутствующий файл, дополняя существующую папку
  и сохраняя пользовательские изменения в уже существующих файлах.

Исходный путь для `plugin.getResource(...)` никогда не меняется преобразованием
пути назначения. Сохранение выполняется напрямую в указанный каталог:
`plugin.saveResource(...)` для этого не подходит, поскольку всегда использует
data folder плагина-источника.

Существующие `saveIfNotExist`, `saveOptionalIfNotExist`, `load`,
`storeToNotExistFolder(File)` и `storeToNotExistFolder(File, Function)` сохранены.
В частности, прежний вызов BMenu со списком файлов и `substring("menu/".length())`
теперь корректно читает ресурсы `menu/...` и сохраняет их относительно папки назначения.

При отсутствии обязательного ресурса выбрасывается `IllegalArgumentException`,
при ошибке файловой системы — `UncheckedIOException`. Отсутствующий ресурс
не создаёт файл назначения. `saveOptionalIfNotExist` возвращает `null` при ошибке.
Копирование нескольких файлов не является транзакцией: при ошибке часть файлов
может уже быть сохранена. Пустой результат шаблона не создаёт папку назначения.
